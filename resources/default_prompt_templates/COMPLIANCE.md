# 默认提示词模板合规说明

本目录下的提示词模板为**官方提供的默认模板**，依照法律与平台规范编写，供「提示词模板导入数据库插件」使用。

## 合规要求

- **严格禁止**：非法内容、政治敏感、色情低俗、暴力恐怖、违法犯罪、违背公序良俗。
- **必须遵守**：中华人民共和国法律法规及相关部门规定，内容健康向上、适合全年龄。
- **审核标准**：所有生成内容需符合内容安全与出版规范，不得涉及真实政党、敏感事件或违法情节。

## 使用方式

通过项目中的**提示词模板导入插件**（`tools/import_prompt_templates.py`）将本目录中的 `templates.json` 导入数据库。  
该插件**仅新增数据库中尚不存在的 key**，不会覆盖或修改你本地已保存的提示词，因此你本地数据库中的提示词与修改前保持一致。

## 文件说明

- `templates.json`：默认提示词列表，每条含 `key`、`description`、`content`。
- 本说明仅供合规与使用参考，不随模板一同写入数据库。
